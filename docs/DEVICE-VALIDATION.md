## 工場出荷状態への初期化

旧版の変更はユーザーごとのパッケージ有効状態と既定ホームの設定で、システムファイルの削除・書き換えは行いません。この仕組みから、通常の工場出荷状態への初期化で純正ホームに戻ると考えられます。ただし、この実機で初期化しての復元は未検証です。

初期化はアプリ、アカウント、Wi-Fi設定なども消すため、通常はADBでの復元を優先します。Google TVの `RecoveryActivity` はアプリの画面であり、端末のリカバリーモードとは別です。Xiaomi TV S Mini LED 55 2025での物理ボタンによるリカバリー起動手順は未確認です。

参考: [Google TVの初期化](https://support.google.com/googletv/answer/10070482?hl=ja)、[Xiaomiの初期化案内（別機種のTV A 55 2025）](https://www.mi.com/global/support/faq/details/KA-481125/)、[AndroidのADBによるパッケージ有効状態の変更制限](https://android.googlesource.com/platform/frameworks/base/+/refs/heads/android13-dev/services/core/java/com/android/server/pm/PackageManagerService.java)。

待機復帰後のQuiet TV表示は確認済みです。再起動・ファームウェア更新後のHomeキー動作は未検証です。

## 方向キーの意図しないリピート・遅延の切り分け

設定アプリでも上・下・右の短押しが連続移動になり、特に上方向では入力が溜まってから反映されるという申告を受け、2026-10-24に次の比較を行いました。

| 接続中のユーザー補助サービス | 実機での結果 |
| --- | --- |
| Button Mapperのみ | 設定アプリで症状をユーザーが確認 |
| なし（Button Mapperを一時停止） | キーフィルタOFFを確認し、ユーザーが解消を確認 |
| Quiet TVのホーム切替・Home直接起動のみ | 方向キーは正常、Homeも直接開くことをユーザーが確認 |
| Quiet TVの2サービス＋Button Mapperを再開 | ユーザーが症状の再発を確認 |

リモコンの生入力を方向キーに限定して一時観測し、短押しのDOWN／UPが対で届くことを確認しました。Button Mapperを通るキー処理経路に原因を絞れましたが、内部の故障箇所と発生契機は未特定です。

調査開始時のQuiet TVのサービス切断は、プロセス終了記録では操作テストの開始・終了に伴う強制停止でした。既存の有効化同意の範囲で再接続し、最終確認では両サービスが接続中、クラッシュ扱いのサービスはなしです。

ユーザーはButton Mapperの割り当てを使っていないため、無効のままにすることを選択しました。Button Mapperのアプリと割り当て情報は保持し、Quiet TVの2サービスは有効にしています。APKとキーリピートのシステム設定は変更していません。

## Home復帰処理の高速化（1.0.7）

`onNewIntent` と `onResume` の両方で行っていた入力取得・画面構築を、後から呼ばれる `onResume` に一本化しました。入力は毎回読み直し、入力ID・名前・並び順・エラー状態が変わらなければホームのViewを再利用します。アプリ一覧の表示中もホームを保持し、戻る／Homeで復帰するときのカード作成を省きます。

同じ実機で、1.0.6と1.0.7に同一のテストAPKを使い、`onNewIntent` → `onResume` のアプリ内同期処理を比較しました。各バージョンで5回のウォームアップ後、31回を測定しています。

| 測定対象 | 1.0.6 | 1.0.7 |
| --- | ---: | ---: |
| 中央値 | 63.780 ms | 20.706 ms |
| p90 | 82.767 ms | 29.006 ms |
| カードを作り直した回数 | 31 / 31 | 0 / 31 |

この測定はライフサイクルメソッドの呼び出しをテスト側で再現したものです。リモコンからのキー配送、描画・画面遷移、電源復帰、コールド起動は含みません。テレビ全体の起動が同じ割合で速くなることを示す数値ではありません。

APK・操作テスト用APKのビルド、Lint（エラー0件）、既存43テストに成功。実機操作テストでは、カード再利用とフォーカス維持、入力名変更・削除、エラー復旧、実際のHome Intentによる一覧からの復帰、従来の方向キー・設定導線・4列と折り返しを確認しました。テスト用APKと生成画像は除去し、通常のホームを起動しています。

操作テスト後は、開始前に記録したQuiet TVの2サービスを復元しました。最終確認では両サービスが接続中、クラッシュ扱いのサービスはなく、Button Mapperは無効のままです。Google TVの入力非表示設定も保持しています。
